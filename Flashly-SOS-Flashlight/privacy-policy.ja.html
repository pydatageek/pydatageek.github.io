プライバシーポリシー — モールス信号 SOS (Morse SOS Flashlight, Flashly)

施行日：2026-10-23
アプリ：Morse SOS Flashlight（「Flashly」）、パッケージ名 com.pydata.flashlysosflashlight
開発者：PyDataGeek（以下「当方」）
連絡先：pydatageekdev@gmail.com

本ポリシーでは、本アプリが取り扱う情報、その理由、およびお客様が選択できる事項について説明します。できるだけ簡潔でわかりやすい内容となるよう心がけています。

本書は翻訳版です。英語版と内容が異なる場合は、英語版が優先されます。

1. 概要

  • 本アプリにはアカウント機能がなく、お客様の氏名、メールアドレス、連絡先、写真、正確な位置情報を求めることはありません。
  • お客様の設定はお使いのデバイス内にのみ保存されます。
  • 本アプリに組み込まれた 2 つの Google サービスが一部のデータを収集します。Google AdMob（バナー広告の表示）と Firebase Crashlytics（クラッシュの報告）です。
  • 欧州経済領域（EEA）、英国およびスイスでは、パーソナライズド広告を表示する前にお客様の同意を求めます。選択内容はいつでも変更できます。

2. 第三者サービスによって収集されるデータ

本アプリ自体は、当方が運営するいかなるサーバーにもデータを送信しません。本アプリに組み込まれた以下の Google サービスが、データを直接収集します。

Google AdMob（バナー広告）

データ目的
広告 ID広告の配信、表示回数の制限（フリークエンシー キャップ）、効果測定、および（同意が必要な地域では同意がある場合に限り）パーソナライズド広告の表示
IP アドレスおよびそこから推定されるおおよその位置情報広告の配信、不正行為の防止、地域ごとの規制への対応
広告とのインタラクションデータ（表示回数、クリック）広告の効果測定と不正行為の防止
基本的なデバイス情報（機種、OS バージョン、言語）お使いのデバイスに適した広告の表示

広告収入により、本アプリを無料で提供し続けることができます。これらのデータの多くについて、Google は独立した管理者として行動します。詳しくは、Google のサービスを使用するアプリから収集した情報の Google による使用方法および Google プライバシー ポリシーをご覧ください。

Firebase Crashlytics（クラッシュレポート、リリースビルドのみ）

データ目的
クラッシュ時のスタックトレース不具合の特定と修正
デバイスの機種、OS バージョン、アプリのバージョン問題の再現
Crashlytics のインストール UUIDクラッシュの影響を受けたインストール数の集計（お客様の身元とは紐付けられません）
タイムスタンプクラッシュ前後の出来事の順序の把握

クラッシュレポートは、アプリがクラッシュした場合にのみ送信されます。お客様の設定、モールス信号のテキスト、入力した内容は一切含まれません。詳しくは Firebase のプライバシー情報をご覧ください。

本アプリは Firebase Analytics やその他の利用状況分析サービスを使用していません。

3. 同意と広告に関する選択

  • 欧州経済領域、英国およびスイス：本アプリを初めて開いたときに、Google の User Messaging Platform (UMP) による同意フォームが表示され、パーソナライズド広告に同意するかどうかを確認します。同意しない場合でも、パーソナライズされていない（制限付きの）広告が表示されることがあります。
  • アプリ内で選択を変更する：設定 → プライバシー → 広告のプライバシー設定を開くと、同意フォームが再度表示され、選択内容を変更できます。
  • Android の設定：設定 → プライバシー → 広告（一部のデバイスでは設定 → Google → 広告）から、広告 ID のリセットや削除、パーソナライズド広告の無効化を行えます。

4. お使いのデバイスにのみ保存されるデータ

本アプリは Android DataStore を使用して、次の設定をお使いのデバイスに保存します。懐中電灯の明るさレベル、スクリーンライトの色と明るさ、SOS の光源、お客様が設定したモールス信号のテキスト、ストロボの速度、自動オフタイマー、および振ってオン/オフする機能の設定です。

これらのデータが当方に送信されることはありません。Android のバックアップを有効にしている場合、これらの設定はお使いのデバイスの Google バックアップ（Android Auto Backup）に含まれることがあり、このバックアップはお客様の Google アカウントの設定に基づき Google が管理します。本アプリをアンインストールするか、アプリのストレージを消去すると、これらのデータは削除されます。

オプションの振ってオン/オフ機能は、本アプリの使用中に限り、デバイスの加速度センサーを読み取ります。センサーデータは端末内で処理され、お使いのデバイスの外に送信されることはありません。

5. 権限

権限使用する理由
INTERNET, ACCESS_NETWORK_STATE広告の読み込みとクラッシュレポートの送信
FOREGROUND_SERVICE, FOREGROUND_SERVICE_SPECIAL_USE画面がオフの間も SOS、モールス信号、ストロボの信号を継続し、停止ボタン付きの通知を表示するため
WAKE_LOCK画面がオフの間も点滅のタイミングを正確に保つため。信号が停止すると解放されます
com.google.android.gms.permission.AD_ID, ACCESS_ADSERVICES_AD_ID, ACCESS_ADSERVICES_ATTRIBUTION, ACCESS_ADSERVICES_TOPICS（Google Mobile Ads SDK により追加）AdMob が広告 ID を読み取れるようにするため、また、対応する Android バージョンでは、Android のプライバシーに配慮した広告 API（Topics および Attribution）を使用するため。広告 ID のリセットや削除、これらの機能の無効化は、設定 → プライバシー → 広告から行えます
POST_NOTIFICATIONS（Android 13 以降、実行時に確認）実行中の信号の通知を表示するため。バックグラウンドで信号を開始する際に確認します。許可しないこともできます

本アプリは、カメラ、マイク、位置情報、連絡先、ストレージの権限を要求しません。懐中電灯機能は Android のトーチ (torch) API を使用しており、カメラへのアクセスは必要ありません。

6. 法的根拠（GDPR／英国 GDPR）

  • パーソナライズド広告：UMP フォームを通じて取得するお客様の同意。同意はいつでも撤回できます（第 3 節参照）。
  • パーソナライズされていない広告：無料アプリの運営資金を確保するという当方の正当な利益。また、必要な場合には、お使いのデバイスへの情報の保存またはデバイス上の情報へのアクセスに関する同意。
  • クラッシュ診断：アプリを安定させ、緊急時にも安心して頼れる状態に保つという当方の正当な利益。

7. データの保持

  • Crashlytics：Firebase の保持ポリシーに従い、クラッシュレポートは Firebase により約 90 日間保持された後、自動的に削除されます。
  • AdMob：保持期間は Google が定めます。Google のデータ保持ポリシーをご覧ください。
  • デバイス上の設定：お客様がアプリのデータを消去するか、アプリをアンインストールするまで保持されます。

8. お客様の権利

お住まいの地域によっては、お客様には、ご自身の個人データへのアクセス、訂正、削除、処理への異議申し立てを行う権利、同意を撤回する権利、および所在地のデータ保護監督機関に苦情を申し立てる権利が認められている場合があります。

当方はお客様を特定できるデータを保有していないため、通常、ご請求をお客様ご本人と結び付けることができません。それでも、pydatageekdev@gmail.com までメールでご連絡いただければ、可能な範囲で Firebase へのクラッシュデータの削除依頼を含め、対応いたします。Google が保有するデータについては、お客様の Google アカウントやデバイスの広告設定もご利用いただけます。

9. お子様について

本アプリは 13 歳未満のお子様を対象としておらず、当方がお子様の個人情報を故意に収集することはありません。お子様のデータが収集されたとお考えの場合は、当方までご連絡ください。削除に向けて対応いたします。

10. セキュリティ

AdMob および Crashlytics が送信するすべてのデータは、通信中に暗号化されます（HTTPS）。当方は本アプリのために独自のサーバーを運用していません。
